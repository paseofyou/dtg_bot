摘要：恶意社交机器人的泛滥严重威胁网络安全与公众信任，实现高效检测至关重要。现有主流方法多依赖图神经网络（GNN）提取社交拓扑特征，然而这类方法在处理用户文本时普遍将账号的全部推文**平均池化**为单一向量，个别异常推文所携带的判别信号被整体均值抹平；另一方面，试图引入时序建模的工作往往依赖完整的高精度时间戳日志，在时间信息受限的真实场景（如 TwiBot-20）中难以适用。针对上述问题，本文提出一种融合事件级注意力与真实结构演化的社交机器人检测框架。在微观层面，本文放弃平均池化，转而保留逐条推文的独立表征，并从**相邻发帖事件之间的转移量**（语义跳变幅度、模板词重叠、转发连段等）构造事件特征序列，再以注意力池化自适应地聚焦于少数异常事件；在宏观层面，本文以账号创建时间为锚点构造**真实**的动态图快照序列，建模邻域结构随时间的演化轨迹，全程不依赖推文级时间戳。二者与关系图神经网络编码的当前全景多关系拓扑经跨视图注意力融合与对比学习对齐，形成统一的联合感知框架。此外，本文设计了顺序敏感性诊断实验，通过打乱、反转用户发帖顺序等对照，系统检验了“发帖先后顺序是否携带判别信息”这一被广泛默认的前提。在 TwiBot-20 上以 15 个随机种子开展的系统实验表明：事件级注意力相比统计池化带来显著且稳定的提升（AUC +4.10，p < 1e-5），而发帖顺序本身的贡献在统计上不可区分（AUC −0.18，p = 0.443），该零效应在 TwiBot-22 上获得独立复现（ΔAUC = +0.01，p = 0.972）；但进一步的对照显示，真实时间戳所携带的连续时间信息（相邻间隔、昼夜相位）提供了超出离散次序的显著增量（ΔAUC 最高 +3.86，p < 1e-15）——这组结果对现有微观时序建模工作"以列表次序代理时间"的基本假设提出了精确修正；完整框架相对可信复现的 BotRGCN 基线取得 AUC +0.28～+0.49 的显著提升（经 Holm 多重比较校正），但在 F1 上未观察到稳定增益。本文同时如实报告三项负面结果：宏观快照演化视图、跨视图注意力融合与 InfoNCE 对齐均未带来增益，其中 InfoNCE 呈现随权重增大而单调恶化的剂量依赖效应，据此提出"视图判别力悬殊时强制对齐会损害强视图"这一对后续架构设计具有警示意义的观察。

1 引言



随着在线社交网络（如 Twitter、Facebook 和微博）的迅猛发展，这些平台已成为全球信息传播和公众意见表达的核心场域。然而，社交平台的开放性也为恶意社交机器人的泛滥提供了可乘之机。社交机器人是由自动化程序控制的社交账号，它们能够模仿人类行为进行大规模的内容发布与社交互动[[1](#_ENREF_1)]。近年来，恶意社交机器人被广泛用于传播虚假信息与低可信度内容[[2](#_ENREF_2)]、干预政治选举[[3](#_ENREF_3)]、 以及激化网络舆论对立[[4](#_ENREF_4)]，严重破坏了在线信息生态的真实性与公众信任。因此，如何高效、准确地检测社交机器人，已成为维护网络空间安全与社交平台健康发展的关键挑战[[5](#_ENREF_5)]。

早期针对社交机器人的检测主要依赖于特征工程与传统机器学习技术，通常从账号元数据和发文统计中提取显式特征，并使用随机森林或支持向量机（SVM）等分类器进行分类[[6](#_ENREF_6)]。随着深度学习的发展，基于长短期记忆网络（LSTM）和卷积神经网络（CNN）的模型被引入，以捕捉推文文本中的语义信息[[7](#_ENREF_7), [8](#_ENREF_8)]。与此同时，研究者注意到机器人在发帖时间上往往表现出有别于人类的阵发性与机械规律，因此开始引入微观时序建模方法[[9](#_ENREF_9)]。例如，部分研究利用循环神经网络处理用户连续的推文时间间隔[[10](#_ENREF_10)]，或将行为序列转化为数字 DNA 符号来寻找协同作案的刻板规律[[11](#_ENREF_11), [12](#_ENREF_12)]。然而，高级社交机器人正处于不断进化之中，它们已经学会了通过窃取真实人类的推文、引入随机时间延迟等方式来伪装自身的文本与行为特征。面对这种蓄意伪装，仅依赖节点文本或单一个体的时序方法极易失效。

为了突破个体特征伪装的瓶颈，研究者的视角逐渐从“个体行为”转向“群体网络结构”。基于图神经网络（GNN）的检测方法，如 BotRGCN[[13](#_ENREF_13)]、RGT[[14](#_ENREF_14)] 等成为近年来的主流，它们通过捕获社交拓扑中的异质关系，有效识别了试图通过互粉来掩饰身份的机器人集群。然而，这类图模型普遍将社交网络视为一张静态快照，完全丢失了历史交互图的上下文信息。认识到这一局限性后，部分前沿工作开始探索动态图与时空建模技术。例如，BotDGT[[15](#_ENREF_15)] 将社交网络切分为动态图快照序列以捕捉网络演化；BotSTHCL[[16](#_ENREF_16)] 则构建了时间感知的社区超图以提取节点在时间维度上的演变特征。

尽管上述工作在各自维度上取得了显著进展，但在处理用户文本这一最直接的证据来源时，主流方法存在一个被长期忽视的共性缺陷：**平均池化**。无论是 BotRGCN、RGT 还是 BotMoE，在构造节点的文本特征时都将账号的全部推文编码后取均值，压缩为单一向量输入图网络。这一操作隐含了"用户的推文在判别上是同质的"这一假设，然而机器人的破绽往往只集中在少数几条推文上——例如某条突兀的推广文案、某段模板化的复读、某次与账号整体语义中心显著偏离的转发。当这少数异常事件被数十甚至数百条正常推文平均之后，其信号在数值上被稀释到近乎消失。粗粒度动态图方法在初始化每个时间快照的节点特征时同样执行了窗口内的平均池化，因此继承了完全相同的缺陷。

另一方面，试图弥补该缺陷的微观时序工作（如数字 DNA、发帖间隔建模）普遍依赖完整的推文级时间戳日志。然而主流基准的时间信息可得性差异极大：TwiBot-22 提供了推文级 `created_at`，而 TwiBot-20 仅提供无时间戳的推文文本列表。这使得依赖精确时间戳的方法难以统一适配。更值得追问的是，这类工作共同默认了一个前提——**发帖的先后顺序本身携带判别信息**——但据我们所知，该前提尚未被严格的对照实验检验过。

基于上述观察，本文提出一种融合事件级注意力与真实结构演化的检测框架（DTG-Bot）。在微观层面，本文放弃平均池化，保留逐条推文的独立表征，并从相邻发帖事件之间的**转移量**构造事件特征序列：包括相邻推文的语义相似度与位移幅度（刻画内容拼接导致的语义跳变）、词级 Jaccard 重叠（刻画模板化复读）、转发连段长度、以及相对账号语义中心的偏离度等；随后以注意力池化替代均值池化，使模型能够自适应地聚焦于少数异常事件。在宏观层面，本文以账号创建时间为锚点生成动态图快照序列，第 k 个快照仅保留两端账号均已在切点 t_k 之前创建的边，从而刻画邻域结构随时间的**真实**演化轨迹；需要强调的是，单一快照数据无法重构用户自身属性的历史取值，因此本文的宏观分支严格限定于结构演化，不对属性演化作任何合成或外推。二者与 RGCN 编码的当前全景多关系拓扑经跨视图注意力融合，并以跨视图对比学习对齐三路表征空间。

本文的主要贡献总结如下：

1、揭示并修正了主流方法中平均池化对微观异常证据的稀释效应。 本文指出现有 GNN 检测方法普遍采用的推文平均池化会抹平少数关键异常事件所携带的判别信号，并据此提出事件级注意力机制：保留逐条推文表征、以相邻事件的转移量构造特征、用注意力池化自适应加权。在 TwiBot-20 上，该机制相比统计池化对照带来 AUC +4.10、F1 +2.01 的提升（15 个随机种子，配对 t 检验 p < 1e-5）。

2、提出了顺序敏感性诊断范式，并给出一个反直觉的实证结论。 本文设计了打乱（shuffle）、反转（reverse）用户发帖顺序的对照实验，用于检验"发帖先后顺序携带判别信息"这一被广泛默认的前提。在 TwiBot-20 上，打乱顺序后模型性能与原始顺序在统计上不可区分（ΔAUC = −0.18，p = 0.443），表明该数据集上的增益完全来自**哪些事件异常**而非**事件的先后次序**。该结论的有效性由双重证据支撑：TwiBot-20 原论文记载推文经 Twitter API 时间线接口倒序抓取，本文亦在同族采集的 TwiBot-22 全量推文上实测到 96.71% 的列表保序率，故"数据集未保序"的替代解释不再悬置；且次序零效应在 TwiBot-22 上被独立复现（ΔAUC = +0.01，p = 0.972）。在此之上，本文在 TwiBot-22 上完成的 order-vs-Δt 对照进一步划定了结论边界：连续物理时间通道（相邻间隔、昼夜相位、星期）提供了显著增量（ΔAUC 最高 +3.86，p < 1e-15），即**无效的是离散的相对先后，而非时间信息本身**。该诊断范式可直接迁移用于审查其他时序建模工作的有效性来源。

3、构建了以真实时间锚点驱动的宏微观联合感知框架，并如实报告了其中未获实证支持的组件。 宏观分支以账号创建时间为唯一时间锚点生成动态图快照序列，全程不依赖推文级时间戳，因而在时间信息受限的数据集上依然可用。在 TwiBot-20 上，完整框架相对可信复现的 BotRGCN 基线（F1 = 87.72，高于官方标称 87.07）取得 AUC +0.28～+0.49 的显著提升（Holm 校正后 $p$ < 0.01），但在 F1 上未观察到稳定增益。同时本文明确报告三项**负面结果**：宏观快照演化视图未优于仅用全局视图，其有效成分实为第二条静态图通路；没有证据表明本文设计的跨视图注意力融合优于保留视图独立通路的简单方案；跨视图 InfoNCE 对齐未带来增益，且呈现随权重增大而单调恶化的剂量依赖效应。三者共同指向一个可推广的观察——当参与融合的视图判别力悬殊时，强制对齐或加权求和会损害强视图。本文提供了包含 13 组变体、每组 15 个种子的完整消融，全部关键对比采用同种子配对 t 检验并施加 Holm-Bonferroni 多重比较校正。

 

2 相关工作

2.1 基于特征的检测方法

早期针对社交机器人的检测通常被建模为标准的监督分类问题，其核心在于从多源异构数据中提取具有高度区分性的个体特征。根据特征维度的不同与提取技术的演进，这类方法可进一步划分为基于静态属性的特征工程、基于深度学习的语义特征建模，以及基于时序行为的动态序列提取。

**基于静态属性与内容的特征工程**：早期的研究工作主要依赖于大量手工构建的特征工程。研究人员广泛探索了从账号元数据（如粉丝数、关注数、账号创建时间等）、推文统计属性以及浅层文本内容中提取显式特征[[17](#_ENREF_17)]。例如，Chu 等人较早地结合了正交稀疏双元组与账户属性，利用随机森林等机器学习算法实现了对自动化账号的初步识别[[18](#_ENREF_18), [19](#_ENREF_19)]。随后，Lee 等人通过一项长达七个月的长期研究，系统性地分析了内容污染者的静态活动特征与网络诱饵规避模式[[20](#_ENREF_20)]。除了基础统计量，部分研究引入了自然语言处理技术来挖掘情感极性等语义暗示，例如 Dickerson 等人便提出通过情感分析来辅助识别试图在政治等敏感话题中操纵舆论的机器人[[21](#_ENREF_21)]。作为此类特征工程方法的集大成者，Davis 等人及其后续的 Varol 等人开发了著名的 BotOrNot系统[[22](#_ENREF_22), [23](#_ENREF_23)]。该系统提取了多达上千维度的元数据、内容、情感和网络特征，并使用集成学习模型在各类基准测试中取得了基石性的检测精度。然而，这类依赖传统机器学习与浅层手工特征的方法，在面对能够轻易篡改个人资料和发布内容的高级伪装机器人时，逐渐显露出特征极易被逃避的脆弱性。

**基于深度学习的语义特征建模**：为了应对社交机器人日益复杂的内容伪装与语义混淆，研究者开始引入深度学习技术以自动提取高维的隐式语义特征。Kudugunta 和 Ferrara 提出了一种基于长短期记忆网络的上下文架构，在推文级别和账户级别分别对文本序列与元数据特征进行深度编码，显著提升了对复杂语义的捕捉能力[[8](#_ENREF_8)]。Wei 和 Nguyen 利用双向长短期记忆网络结合词嵌入技术，在不需要人工干预的情况下有效提取了推文序列的上下文深层语义[[24](#_ENREF_24)]。此外，Cai 等人通过联合建模行为特征和内容信息，利用CNN进一步增强了模型对局部异常语义模式的捕获能力[[7](#_ENREF_7), [25](#_ENREF_25)]。近年来，随着预训练大语言模型的兴起，RoBERTa 等先进模型也被广泛应用于提取独立于特定话题的深层语境特征中[[26](#_ENREF_26)]。

**基于时序行为的动态特征提取**：由于仅仅依赖静态元数据和单条内容特征容易被高级机器人通过窃取真实推文绕过，研究者们意识到自动化脚本控制的发帖节律往往难以完美模仿人类的随机性与复杂性。Pan 等人提出仅依赖微观发帖行为时序特征的检测方法，证明了发帖时间间隔的突发性（Burstiness）和时间熵（Entropy）在区分自动化行为与人类行为时具有强大的鉴别力。在时序序列模式挖掘方面，Chavoshi 等人开发了 DeBot 系统，通过对大量用户活动的动态时间序列进行动态时间规整（Dynamic Time Warping）与扭曲相关性分析，有效检测出了在时间维度上表现出高度同步性的僵尸网络。Mazza 等人提出的 RTbust 模型则利用 LSTM 的变体，直接从用户的转推时间序列中提取潜在的机器自动化时间模式。此外，Cresci 等人创造性地提出了数字 DNA 方法（Digital DNA），将用户行为（如发帖、回复等）编码为离散的基因序列，通过计算最长公共子序列以寻找异常的协同作案规律。Gilmary 等人进一步通过计算近似熵（Approximate Entropy）和样本熵，定量刻画了自动化时间序列中的机械性与低复杂性规律。

尽管上述基于多维特征和序列模型的方法在个体维度的检测上取得了丰硕成果，但它们普遍将社交账户视为孤立的个体，仅关注节点自身的属性演化或单模态的时间规律，忽略了社交网络中广泛存在的异质交互与群体拓扑结构。当高级社交机器人通过窃取真实用户的发文历史，并利用僵尸网络进行互粉和虚假社区构建时，仅依赖个体特征或纯序列的模型往往面临特征失效的困境。这促使研究者的视角从个体特征转向图拓扑网络。

2.2 基于图神经网络的检测方法

随着高级社交机器人开始利用僵尸网络（Botnets）和水军策略进行协同伪装（如批量互粉、社区渗透等），仅依赖个体特征的检测模型由于缺乏全局视野而极易失效。因此，研究者的视角逐渐从“个体属性”转向“网络拓扑结构”，基于图神经网络（Graph Neural Networks, GNNs）的检测方法迅速成为该领域的前沿主流。根据对时间维度的处理方式，现有的 GNN 检测方法经历了从静态结构建模到动态时空融合的演进。

**基于静态图神经网络的结构建模** 为了捕获社交网络中复杂的拓扑依赖关系，早期的图检测方法尝试直接将标准的图卷积网络（GCN）、GraphSAGE 或图注意力网络（GAT）应用于社交同质图上，通过聚合邻居节点的特征来识别异常的机器人集群。然而，在线社交网络本质上是包含多种交互行为（如关注、粉丝、提及、回复等）的异质图。为了更精准地刻画多关系拓扑，Ali Alhosseini 等人率先探索了基于归纳表示学习的垃圾机器人检测；随后，Feng 等人提出的 BotRGCN 模型引入了关系图卷积网络（RGCN），为不同类型的交互边分配独立的权重通道，显著提升了对非对称关注网络的鉴别能力。在此基础上，研究者进一步融合了更复杂的注意力机制与多模态信息，例如 RGT 提出了关系图 Transformer 以捕获异质邻居的动态影响力；BotMoE 更是设计了基于混合专家系统（MoE）的架构，对图拓扑、文本和元数据进行特定模态的专家路由与融合；BIC 模型则探索了文本与图结构的深层交互机制，以捕获由于内容盗用引发的语义不一致性。

**动态图与时空融合检测的兴起** 尽管上述静态图方法（如 BotRGCN、BotMoE）在多模态融合上取得了显著性能，但它们普遍将社交网络视为单一时刻的“绝对静态快照”（Static Snapshot）。这种设定完全丢弃了节点特征与图结构随时间推移的历史演化轨迹，难以识别出“长期潜伏、瞬间爆发”的高级机器人伪装。为了弥补这一盲区，最前沿的研究开始向动态图与时空联合建模迈进。例如，He 等人提出的 BotDGT 模型将社交网络切分为多个动态图快照序列，并使用时间感知 Transformer 来捕捉网络拓扑的宏观演化趋势；Liu 等人提出的 BotSTHCL 则构建了时间感知的社区时空超图，并利用对比学习提取高阶的时空交互特征。在多特征时空融合方面，最新的 MSTBC 模型尝试通过双线性模型对时序行为、社交结构和描述内容进行多行为对比学习，以有效缓解跨模态融合时产生的噪声累积；Yang 等人提出的 RoSGAS 则利用深度强化学习自动搜索自监督的 GNN 架构，以适应社交机器人不断演化的动态特征。

综上所述，从静态图到动态图的演进显著提升了检测性能，但在**文本证据的聚合方式**上，各类方法高度一致地采用了平均池化：静态图方法对账号的全部推文取均值，动态图方法则对每个时间窗口内的推文取均值。这一共性操作使得少数关键异常推文的信号被大量正常推文稀释，构成了一个跨范式的共同盲区。另一方面，尽管 MSTBC 等方法引入了多模态对比学习，但它们仍缺乏对"历史演化轨迹"与"当前全景多关系拓扑"的差异化互补建模。

尤为值得注意的是，上述引入微观时序的工作（数字 DNA、RTbust、间隔与熵建模等）均建立在"发帖先后顺序携带判别信息"这一前提之上，但该前提本身从未被打乱顺序类的对照实验直接检验过——现有工作通常只报告"加入时序模块后性能提升"，而性能提升亦可能来源于额外参数量、或来源于事件的**内容**特征而非其**次序**。区分这两种来源需要专门的顺序敏感性对照，这正是本文实验部分的一项重点内容。

有鉴于此，本文提出 DTG-Bot 框架。在微观层面，以事件级注意力替代平均池化，从相邻发帖事件的转移量构造特征并自适应聚焦异常事件；在宏观层面，以账号创建时间为锚点构造真实的动态图快照序列，建模邻域结构演化；最后通过跨视图注意力融合与对比学习，将上述两路特征与当前全景 RGCN 拓扑对齐。此外本文提供顺序敏感性诊断，明确区分性能增益究竟来自事件内容还是事件次序。

 

3 问题定义与威胁模型

3.1 社交网络图形式化

本文将在线社交平台建模为一张异质多关系图 $G=(V, E, \mathcal{R})$。其中 $V$ 为账号节点集合；$\mathcal{R}=\{\text{following}, \text{follower}\}$ 为关系类型集合；$E \subseteq V \times V \times \mathcal{R}$ 为带关系类型的有向边集合，$(u,v,r)\in E$ 表示账号 $u$ 与 $v$ 之间存在类型为 $r$ 的社交关系。

每个节点 $u\in V$ 关联三类观测信息：

（1）**账号属性**：包括数值型属性 $\mathbf{x}^{num}_u\in\mathbb{R}^{7}$（粉丝数、关注数、推文数、被列数等计数特征）与类别型属性 $\mathbf{x}^{cat}_u\in\mathbb{R}^{3}$（是否认证、是否启用默认头像等），以及账号自我描述文本 $d_u$；

（2）**发帖事件集合**：账号 $u$ 的最近若干条推文原文构成事件集合 $\mathcal{T}_u=\{t_{u,1},t_{u,2},\dots,t_{u,n_u}\}$，$n_u$ 以平台返回上限为界。需要强调的是，$\mathcal{T}_u$ 中的元素是**独立的发帖事件**，本文不假定其携带可利用的物理时间信息（详见 3.4 节）；

（3）**账号创建锚点**：每个账号附有一个真实可查的注册时间戳 $c_u$（即 `profile.created_at` 字段），这是本文唯一依赖的时间信号。

3.2 检测任务定义

社交机器人检测被形式化为图上的**半监督节点二分类**任务。给定图 $G$ 中只有部分节点带有标签：记标注子集为 $V_L\subset V$，每个 $u\in V_L$ 具有标签 $y_u\in\{0,1\}$（1 表示机器人，0 表示人类）；其余节点为无标签的支撑节点，仅参与图上的消息传递而不直接提供监督信号。目标是学习映射 $f:V\to\{0,1\}$，使标注节点上的分类误差最小，并对未见账号保持泛化。

本文遵循基准数据集的官方划分。以 TwiBot-20 为例，标注节点共 11826 个，按 train / dev / test = 8278 / 2365 / 1183 划分，另有约 21.8 万个无标签支撑节点参与图传播；类别存在明显不平衡，因此除 Accuracy 外同时报告 F1、MCC 与对阈值不敏感的 AUC。

3.3 威胁模型

**攻击者能力。** 本文面向的高级社交机器人具备如下伪装能力：（i）**内容拼接**——窃取或复述真实人类的推文，将其与模板化推广文案混合发布，使账号整体语义趋近正常用户；（ii）**模板化复读**——少量推文被批量复制、仅替换少量实体词；（iii）**互粉构团**——通过僵尸网络批量互粉、渗透正常社区，使局部拓扑不再呈现明显异常；（iv）**冷启动与间歇活跃**——长期潜伏后在事件窗口内集中行动。

**防御者观测。** 防御方只能访问数据采集时刻的**单次快照**：账号当前属性、当前邻居列表与最近推文列表。本文明确声明两点边界：

（1）**不依赖推文级物理时间戳**。主流基准中 TwiBot-20 不提供推文 `created_at`，因此任何需要精确发帖时刻的方法在该场景下不可用。本文的全部判别信号均不要求该信息：微观分支使用的事件特征在事件集合的任意排列下不变（见 4.2 节），宏观分支仅使用账号级创建锚点。

（2）**边形成时间不可直接观测**。快照数据中无法获知某条边何时建立。本文采用保守上界：一条边仅当其两端账号均已在时刻 $t$ 之前创建时才被认为在 $t$ 时刻存在。该假设不引入任何合成数据，仅是对"该边在 $t$ 时刻是否可能存在"的确定性判定。

3.4 时间信息可得性分级

不同基准数据集提供的时间信息粒度差异极大，这直接决定了各类方法的适用范围。本文将时间信息可得性分为三级，并对照两个主流基准：

**表 1  主流基准的时间信息可得性对照**

| 时间信号 | TwiBot-20 | TwiBot-22 | 本文是否使用 |
|---|---|---|---|
| 账号创建时间 `created_at` | ✓（缺失率 0%） | ✓ | ✓（宏观快照锚点） |
| 推文列表顺序 | ✓（API timeline 倒序抓取，见文献机制） | ✓（全量实测违例率 3.29%，见 5.3 节） | 仅用于诊断实验 |
| 推文级 `created_at` | ✗ | ✓ | ✗（主模型不使用） |

其中"推文列表顺序"一行如今具备**文献机制与实证双重支撑**，而非仅是惯例假定。文献层面，TwiBot-20 原论文明确记载其推文通过 Twitter API 的用户时间线接口检索"每用户最近 200 条推文"[[27](#_ENREF_27)]，该接口的返回规范默认按发布时间倒序排列，即数据集构建时在采集端即已保序。实证层面，本文在 TwiBot-22 全量推文上直接测量了同一采集范式下的列表有序性：扫描 88,217,457 条推文、933,872 名作者、87,283,585 个相邻推文对，其中时间倒序违例 2,875,870 对，**违例率仅 3.29%**——即 96.71% 的相邻对保序。需要说明的是，从作者维度看有 **57.40% 的作者至少出现一次违例**，故列表并非严格有序，不宜把列表位次当作精确的时间秩；但在"列表顺序是否大体等价于时间顺序"这一本文所关心的问题粒度上，保序性是充分的。需保留的一点克制是：TwiBot-20 自身不含推文时间戳，无法在其内部逐条核验，上述判断依赖"同族采集范式"的证据链，属于强支撑而非该数据集内部的直接测量。

本文方法按**最低可得性**设计：仅依赖账号级创建锚点与顺序无关的事件级特征，因此在两个基准上均可运行。TwiBot-22 额外提供的推文级时间戳不被主模型使用，而是作为**验证台**使用：本文在其上完成了 order-vs-$\Delta t$ 对照，实测发现连续物理时间信息（相邻发帖间隔 $\Delta t$、昼夜相位、星期）携带了离散次序所没有的判别增量（见 5.3 节测量二），这为时间信息更丰富的场景预留了明确的扩展方向。

4 DTG-Bot 方法

4.1 总体架构

DTG-Bot 由三个互补的表征视图与一个跨视图融合模块构成，如图 1 所示：

（1）**微观视图**：保留逐条推文的独立表征，从相邻发帖事件之间的转移量构造事件特征，经 Transformer 交互与注意力池化得到用户级表示 $\mathbf{z}^{mi}_u$，解决平均池化对异常事件的稀释问题；

（2）**宏观视图**：以账号创建时间为锚点，将全图切分为 $K$ 个真实结构快照，由共享权重的 RGCN 逐快照编码后沿时间维聚合，得到邻域结构演化表示 $\mathbf{z}^{ma}_u$；

（3）**全局视图**：在当前全景多关系图上以独立的 RGCN 编码节点，得到静态拓扑表示 $\mathbf{z}^{gl}_u$。

三个视图均为 $d$ 维向量，经跨视图注意力融合为 $\mathbf{z}_u$ 后送入分类头；训练时以交叉熵损失为主，辅以视图两两之间的 InfoNCE 对比损失对齐表征空间。

4.2 微观分支：事件级注意力

**事件特征构造。** 对账号 $u$ 取最近 $L$ 条推文，第 $i$ 条经 RoBERTa 编码为 $\mathbf{e}_i\in\mathbb{R}^{768}$（padding 位记掩码 $m_i=0$）。主流方法在此直接对 $\{\mathbf{e}_i\}$ 取均值，本文则保留逐条表征，并为每个事件构造 14 维特征 $\mathbf{f}_i\in\mathbb{R}^{14}$，分三组：

*逐条通道*（7 维）：对数长度、是否 RT 开头、hashtag 数、mention 数、URL 数、大写比率、数字比率；

*转移通道*（5 维）：刻画相邻两次发帖事件之间"发生了什么变化"：

$$\mathrm{has\_prev}_i=\mathbb{1}[i>0],\quad \cos^{prev}_i=\cos(\mathbf{e}_i,\mathbf{e}_{i-1}),$$

$$l2^{prev}_i=\lVert\hat{\mathbf{e}}_i-\hat{\mathbf{e}}_{i-1}\rVert_2,\quad \mathrm{jac}_i=\frac{|W_i\cap W_{i-1}|}{|W_i\cup W_{i-1}|},\quad \mathrm{rt\_run}_i=r_i/10,$$

其中 $\hat{\mathbf{e}}_i=\mathbf{e}_i/\lVert\mathbf{e}_i\rVert$，$W_i$ 为去除 RT 前缀、@提及与链接后的词集合，$r_i$ 为当前连续转发段的长度。$\cos^{prev}$ 的低值与 $l2^{prev}$ 的高值是"窃取内容拼接"导致语义生硬跳变的直接观测量；$\mathrm{jac}_i$ 与 $\mathrm{rt\_run}_i$ 分别刻画逐词模板复读与批量转发行为；

*上下文通道*（2 维）：相对账号语义中心的偏离与历史自重复度：

$$\cos^{cen}_i=\cos(\mathbf{e}_i,\bar{\mathbf{e}}),\qquad \mathrm{self\_rep}_i=\max_{j<i}\cos(\mathbf{e}_i,\mathbf{e}_j),$$

其中 $\bar{\mathbf{e}}$ 为该用户全部有效推文单位向量的均值方向——恰为主流方法所用的池化向量，因此 $\cos^{cen}_i$ 直接度量"该事件被平均池化抹掉的偏离量"。

序列长度保持为 $L$，需要前驱的通道在 $i=0$ 处置零并由 $\mathrm{has\_prev}$ 标记。全部通道仅用训练集统计量做 z-score 归一化，二值与比率通道保持原值。

**事件编码与注意力池化。** 事件序列先经线性投影与 LayerNorm，再由 Transformer 编码器建模事件间交互得到 $\{\mathbf{h}_i\}$，随后以加性注意力池化聚合：

$$\alpha_i=\mathrm{softmax}_i\!\left(\mathbf{v}^{\top}\tanh(\mathbf{W}\mathbf{h}_i)\right),\qquad \mathbf{z}^{mi}_u=\sum_{i:\,m_i=1}\alpha_i\,\mathbf{h}_i.$$

对零推文账号（全 padding 行），池化退化为零向量，避免 softmax 产生 NaN。

**顺序无关性声明。** 本文刻意**不引入位置编码**：第 5.3 节的诊断实验表明，在 TwiBot-20 上打乱事件次序后性能与原始顺序在统计上不可区分（$\Delta\mathrm{AUC}=-0.18$，$p=0.443$），即判别信号来自"哪些事件异常"而非"事件先后"。因此微观分支在功能上等价于对一个**无序事件集合**做置换不变的注意力聚合，不依赖于对推文列表有序性的任何假设——即便列表有序性的外部证据不充分，该分支的结论也不受影响。位置编码仅以开关形式保留，专供顺序敏感性诊断实验使用。

4.3 宏观分支：真实动态图快照演化

**快照构造。** 以全部节点的创建时间 $c_u$ 为唯一时间锚点，取其 $K$ 个等距分位数作为切点 $t_1<t_2<\cdots<t_K$（本文取 $K=8$）。第 $k$ 个快照的边掩码定义为：

$$M_k(u,v,r)=\mathbb{1}\!\left[\max(c_u,c_v)\le t_k\right],$$

即仅保留两端账号在 $t_k$ 之前均已创建的边，回答"在 $t_k$ 时点这张图是什么样子"。$c_u$ 缺失的节点按最早处理（始终存在），避免整条边被排除。分位数切点而非等距切点保证每个快照有足量新增结构；在 TwiBot-20 上边覆盖从 3.2% 单调增长至 100%（2009 至 2020 年）。

**演化编码。** $K$ 个快照共享同一套两层 RGCN 权重，逐快照得到节点状态 $\mathbf{h}^{(k)}_u$；随后沿快照维用单向 GRU 聚合，取末态作为宏观表示：

$$\mathbf{h}^{(k)}=\mathrm{RGCN}\!\left(\mathbf{x},\, E\odot M_k\right),\quad k=1,\dots,K;\qquad \mathbf{z}^{ma}_u=\mathrm{GRU}\!\left(\mathbf{h}^{(1)}_u,\dots,\mathbf{h}^{(K)}_u\right).$$

共享权重使参数量不随 $K$ 增长，并强制模型学习跨时间稳定的结构模式而非某一切点的特例。

**建模边界声明。** 单次快照数据无法重构用户自身属性的历史取值，任何"属性演化曲线"都只能是合成的。因此本分支严格限定建模对象为**邻域结构随创建锚点的真实演化**——机器人"晚注册、批量互粉"所形成的结构接入模式在该视图中表现为与人类"渐进式积累邻居"显著不同的轨迹，而全程不引入任何合成时序数据。仅取最后一个快照（$t_K$ 时刻的全图）作为本分支的消融对照。

4.4 全局分支：当前全景拓扑

全局分支在不加任何掩码的完整图 $G$ 上运行独立的 RGCN，编码当前时刻的全景多关系拓扑：$\mathbf{z}^{gl}=\mathrm{LayerNorm}(\mathrm{RGCN}(\mathbf{x},E))$。该分支在功能上等价于 BotRGCN 的图通路，承担两项职责：一是提供与宏观分支互补的"终态"结构信息（宏观分支刻画演化轨迹，全局分支刻画当前稳态）；二是作为与主流方法对齐的基准视图，保证融合增益可归因于新增视图而非图通路差异。

两个图分支共享同一个静态特征编码器：账号描述与池化推文（各 768 维）、数值属性（7 维）与类别属性（3 维）分别投影后拼接为 $\mathbf{x}\in\mathbb{R}^{d}$，作为 RGCN 的输入节点特征。

4.5 跨视图融合与对比对齐

**视图注意力融合。** 为避免钦定某一视图为主导，以三视图拼接作为打分依据：

$$w_v=\mathrm{softmax}_v\!\left(\mathrm{MLP}\!\left[\mathbf{z}^{mi}\,\Vert\,\mathbf{z}^{ma}\,\Vert\,\mathbf{z}^{gl}\right]\right),\qquad \mathbf{z}_u=\mathrm{LN}\!\left(\mathrm{Linear}\!\left(\sum_{v}w_v\,\mathbf{z}^{(v)}_u\right)\right).$$

简单拼接（concat）与逐维门控（gate）作为融合方式的消融对照，单视图/双视图组合用于视图消融。

**跨视图对比对齐。** 三个视图刻画同一账号的不同侧面，其表征应互为正样本、异账号互为负样本。对任意两个视图 $a,b$ 施加对称 InfoNCE 损失：

$$\mathcal{L}_{CL}^{(a,b)}=-\frac{1}{2N}\sum_{i=1}^{N}\left[\log\frac{e^{s(\mathbf{z}^{a}_i,\mathbf{z}^{b}_i)/\tau}}{\sum_{j}e^{s(\mathbf{z}^{a}_i,\mathbf{z}^{b}_j)/\tau}}+\log\frac{e^{s(\mathbf{z}^{a}_i,\mathbf{z}^{b}_i)/\tau}}{\sum_{j}e^{s(\mathbf{z}^{b}_i,\mathbf{z}^{a}_j)/\tau}}\right],$$

其中 $s(\cdot,\cdot)$ 为余弦相似度，温度 $\tau=0.5$；为控制百万节点规模下的相似度矩阵开销，每批对节点子采样至 4096。三视图两两求均值记为 $\mathcal{L}_{CL}$。总训练目标为：

$$\mathcal{L}=\mathcal{L}_{CE}+\lambda\,\mathcal{L}_{CL},$$

其中 $\mathcal{L}_{CE}$ 为标注节点上的二分类交叉熵，$\lambda$ 为对比损失权重。

5 实验与分析

5.1 实验设置

**数据集与划分。** 主实验在两个主流基准上进行。（1）**TwiBot-20**：含 11826 个标注用户，按官方文件本身划分 train / dev / test = 8278 / 2365 / 1183（test 中机器人 640、人类 543），另有约 21.8 万个无标签支撑节点参与图传播；每用户推文列表上限 200 条，中位数恰为 200；节点 `created_at` 缺失率为 0%，宏观快照的边覆盖从 3.2% 单调增长至 100%。（2）**TwiBot-22**：含约 100 万用户与推文级真实 `created_at`，用于主实验复测与 5.3 节所述的 order-vs-$\Delta t$ 对照。

**评估协议。** 所有关键对比均运行 **15 个随机种子**（42、123、456、789、2024、7、13、99、2025、314、1618、271、577、999、8128），同一组超参数用于同一比较内的全部变体；按验证集 F1 选择检查点，测试集仅在最后评估一次。报告 Accuracy、Precision、Recall、F1、MCC 与 AUC 的 mean ± std；对关键对比施加**配对 t 检验**（同一组种子下逐对差值），其中 AUC 对分类阈值不敏感，作为稳定性优先的判据。由于本文共实施 5 个对比族、合计 56 项确认性检验，若逐项按 $\alpha=0.05$ 判读将产生约 3 项假阳性，故所有 p 值均施加 **Holm-Bonferroni 族内校正**（记为 $p_{\text{holm}}$），显著性判定一律以校正后的值为准，原始 p 值仅作参考同时列出；文中另对全部 56 项检验做了一次更保守的全局 Holm 校正，用于标识最稳健的若干结论。需要说明的是，本文在初步实验中发现 5 个种子不足以判定 1 个百分点以内的差异，因此 5 种子结果仅用于超参粗筛，不进入本文任何结论。

**实现细节。** 文本编码采用 RoBERTa-base（冻结参数，max\_tokens = 64，fp16 预计算嵌入）：账号描述取单条编码，微观分支取每用户最近 $L$ 条推文的事件序列。为忠实复现 BotRGCN 基线，其图通路的推文输入采用与官方实现一致的池化设置 `--pool-cap 20`（每用户至多取 20 条推文均值池化）；本文微观分支不使用该上限的池化表示，而保留逐条事件表征。图分支为两层 RGCN（关系数 2：following / follower），宏观快照数 $K=8$；对比损失温度 $\tau=0.5$、权重 $\lambda$ 的取值在 5.4 节做敏感性分析。所有结果均记录于 `experiments/results.csv` 并附带 git commit，仅干净 commit 的结果进入本文。

5.3 顺序敏感性诊断

现有微观时序建模工作普遍默认"用户发帖的先后顺序携带判别信息"，并据此引入循环网络、Transformer 或序列模式挖掘模块。然而这些工作通常仅报告"加入时序模块后性能提升"，而该提升存在三种彼此混淆的可能来源：（i）事件的**先后次序**；（ii）事件自身的**内容与形态**，与次序无关；（iii）时序模块引入的**额外参数量**。若不加以区分，则无法判断所谓"时序建模"是否名副其实。本节设计对照实验对三者进行分离。

**实验设计。** 为排除图结构与账号元数据的干扰，本节使用**仅含微观分支**的分类器：输入为用户的事件特征序列，经 Transformer 编码与注意力池化后直接分类，不接入任何图信息或静态属性。设置四个变体：

（1）**keep**：按时间正序（旧→新）输入，即常规设定；

（2）**shuffle**：对每个用户的有效事件位**独立随机打乱**，事件集合不变、仅次序被破坏。若 keep 显著优于 shuffle，说明次序确实携带信息；

（3）**reverse**：整体反序输入，检验模型是否依赖时间方向性；

（4）**bag**：移除自注意力与位置编码，仅对事件特征做均值/标准差统计后经 MLP 分类。该变体保留全部事件内容信息而彻底丢弃事件的个体性与次序，是"注意力聚合是否有价值"的对照。

需要特别指出一个易被忽略的实验有效性条件：Transformer 自注意力与注意力池化**均为置换等变**，若不引入位置编码，编码器输出对输入次序完全不变，此时 shuffle 在构造上不可能改变任何结果，顺序检验将退化为空检验。因此本节所有序列变体均**启用可学习位置编码**，确保模型具备利用次序的能力；只有在此前提下，shuffle 不掉点才能被解释为"次序确实不含判别信息"。本文在实现中验证了这一点：关闭位置编码时 keep 与 shuffle 的输出差异为 $7\times10^{-7}$（浮点误差量级），开启后为 $2.2\times10^{-2}$。

数据集为 TwiBot-20 官方划分，每用户取最近 $L=32$ 条推文，按 5.1 节协议运行 15 个种子。**表 4** 与**表 5** 报告测试集结果与配对 t 检验。

**表 4  顺序敏感性诊断结果（TwiBot-20，仅微观分支，15 个种子，mean ± std，%）**

| 变体 | Accuracy | F1 | AUC |
|---|---|---|---|
| keep（时间正序） | 70.32 ± 1.11 | 74.46 ± 0.89 | 77.65 ± 0.72 |
| shuffle（打乱次序） | 70.13 ± 1.07 | 74.58 ± 0.78 | 77.83 ± 0.48 |
| reverse（整体反序） | 70.09 ± 1.53 | 74.43 ± 1.21 | 77.59 ± 0.91 |
| bag（去注意力，统计池化） | 67.57 ± 1.06 | 72.46 ± 0.58 | 73.55 ± 0.69 |

**表 5  配对 t 检验（keep vs 各对照，n = 15）**

| 对照 | ΔF1 | t | p | ΔAUC | t | p |
|---|---|---|---|---|---|---|
| shuffle | −0.12 | −0.369 | 0.718 | −0.18 | −0.789 | 0.443 |
| reverse | +0.03 | +0.122 | 0.905 | +0.06 | +0.270 | 0.791 |
| bag | **+2.01** | +7.289 | **< 1e-5** | **+4.10** | +14.936 | **< 1e-5** |

结果给出两个清晰而方向相反的结论。

**其一，发帖次序不携带可利用的判别信息。** 打乱每个用户的事件次序后，模型性能与原始时间正序在统计上完全不可区分（ΔF1 = −0.12，p = 0.718；ΔAUC = −0.18，p = 0.443），点估计甚至略偏向 shuffle；整体反序同样无影响（p = 0.905）。考虑到位置编码已启用、模型具备利用次序的能力，该结果表明 TwiBot-20 上的判别信号与事件排列无关。值得记录的是，在仅使用 5 个种子的初步实验中，keep 相对 shuffle 曾呈现 ΔF1 = +0.59（p = 0.088）的表观优势，扩展至 15 个种子后该差异彻底消失（ΔF1 = −0.12）——这提示此类 1 个百分点以内的比较对种子数极为敏感，仅用 3～5 个种子极易得出假阳性结论。

**其二，事件级注意力聚合具有极强价值，且该价值与次序无关。** keep 相对 bag 取得 ΔAUC = +4.10（p < 1e-5）的显著提升；而 shuffle 相对 bag 同样显著（点估计亦为 +4.10 量级）。这说明增益并非来自"按时间顺序建模"，而来自模型对**个别事件**的区分与加权能力：bag 变体虽保留全部事件的内容信息，但压缩为均值与方差后少数异常事件的信号被稀释，注意力池化则能把权重集中到这些事件上。

由此可将本文微观分支的作用机制明确表述为：**关键在于识别哪些发帖事件异常，而非它们何时发生。** 这一结论也从反面解释了以 BotRGCN 为代表的主流方法的局限——其对推文取平均的做法本质上等价于 bag 变体的池化方式，因而系统性地损失了这部分信号。

**结论的适用边界。** 上述空结果需要排除一种替代解释：若 TwiBot-20 的推文列表在构建过程中本未保序，则 keep 与 shuffle 在输入分布上本就等价，实验将不能否证"次序含信息"这一原假设。本文从两个方向获得了该保序假设的支撑。**文献机制层面**：TwiBot-20 原论文明确记载推文通过 Twitter API 的用户时间线接口检索"每用户最近 200 条推文"[[27](#_ENREF_27)]，而该接口的返回规范默认按发布时间倒序排列——即数据集在采集端即已按时间倒序写入。**实证层面**：本文在与 TwiBot-20 同族采集范式下构建的 TwiBot-22 全量推文上直接测量了列表有序性——88,217,457 条推文、87,283,585 个相邻推文对中时间倒序违例率仅 **3.29%**（见表 6），即 96.71% 的相邻对保序。两重证据结合表明，"列表顺序 ≈ 时间顺序"对该系列基准而言有充分依据，"数据集未保序"不再构成悬而未决的替代解释。仍须保留一点措辞上的克制：TwiBot-20 自身不含推文时间戳，其列表有序性无法在数据集内部逐条核验，本文的支撑属于"文献机制 + 同族数据集实测"的证据链；但该证据链已足以支撑 5.3 节结论的主要效力——**在 TwiBot-20 的实验设置下，事件次序未提供可被模型利用的判别信息**，且这一发现具备内外部效度，足以对"离散事件序列的先后次序在当前社交机器人检测任务中不携带可利用判别信息"这一命题给出实质性支持。

需要说明，本数据集上仅微观分支的分类器整体偏弱（AUC 处于 56～62 的区间，测试集 bot 占比约 29%，F1 普遍低于 20%），这与 TwiBot-22 以图结构为主要判别信号的特性一致；因此本节一律以 AUC 为准、不依赖 F1 的绝对水平（F1 列仅为完整性保留）。该设置下得出三条结论。

（1）**离散次序的零效应在外部数据集上严格复现。** 在列表已被实测保序的 TwiBot-22 上，打乱次序后模型性能与原序完全不可区分（ΔAUC = +0.01，$p_{\text{holm}}$ = 0.972）；加入时间通道后亦然（ΔAUC = −0.71，$p_{\text{holm}}$ = 0.185）。这是与 TwiBot-20 相互独立的第二次观察——keep 与 shuffle 的输入差异在两个数据集上都是**真实存在的**，而模型始终无法从中获益。据此，"离散事件序列的先后次序不携带可利用的判别信息"这一命题获得内外部双重效度支持。

（2）**但"时间信息整体无用"被否证：连续物理时间携带离散次序所没有的增量。** 附加真实时间通道后，AUC 显著提升——注意力变体 +1.62（$p_{\text{holm}}$ = 0.0003），统计池化变体 +3.86（$p_{\text{holm}}$ < 10⁻¹⁵）。两条路径同向显著，说明增量来自时间信息本身而非与序列模型的交互。这精确地划定了 5.3 节结论的边界：**无效的是"相对先后"这种粗粒度次序，而非时间信息本身**——发帖间隔的分布形态与昼夜/星期节律确实携带了判别信号（如自动化账号的机械等间隔、缺失昼夜节律等）。

（3）**一个超出预期的发现：事件级注意力在 TwiBot-22 上未复现，甚至反向。** 统计池化（bag）的 AUC 在两个特征组下均显著优于 Transformer 注意力（−1.98 与 −4.22，均经校正显著）。这与 TwiBot-20 上"注意力聚合相对统计池化 ΔAUC = +4.10"的结论相反。本文如实报告该矛盾，其最可能的解释是特征-任务适配问题：本节微观特征的判别力主要来自少数时间/形态统计量，在弱信号数据集上（T22 微观分支接近随机），序列交互层的容量反而拟合了噪声。这一观察**收窄而非推翻** 5.3 节的结论——事件级注意力的价值在 TwiBot-20 上是确凿的（且是完整模型 AUC 增益的来源，见 5.4 节），但它并非无条件成立，其有效性依赖于事件特征本身的信噪比。

5.5 结果讨论

综合 5.2 至 5.4 节，本文的三项技术组件获得的实证支持强弱不一，有必要明确区分。

**获得支持的是事件级注意力。** 其证据来自两条彼此独立的路径：一是 5.3 节在仅微观分支设置下，注意力聚合相对统计池化取得 ΔAUC = +4.10（$p$ < 10⁻⁵）；二是 5.4 节在完整模型中，微观视图叠加到两种不同图骨干上均取得同向显著的 AUC 提升（+0.28 与 +0.20，$p_{\text{holm}}$ = 0.027 与 0.0031），其中后者在对全部 56 项检验的全局 Holm 校正下仍然成立。前者证明"在一组推文中挑出异常的几条"这一机制本身有效，后者证明该信息与图结构证据**互补而非冗余**。同时应当承认两点。其一，其在完整模型中的效应量（AUC 约 +0.2～+0.3）远小于在孤立设置下的效应量（AUC +4.10）——这说明图结构已经捕获了大部分判别信号，事件级证据的边际贡献有限。其二，该支持**仅存在于 AUC 上**：对应的 F1 增益（+0.25 与 +0.08）均不显著。考虑到 AUC 度量的是排序质量而 F1 依赖固定阈值，一个与数据一致的解读是，微观证据主要改善了模型对困难样本的**排序**，但不足以把它们推过决策阈值；这对于需要输出可靠风险排序的实际风控场景仍有价值，但不应被表述为"检测准确率的提升"。其三，**该结论存在数据集依赖性**：在 TwiBot-22 的 order-vs-Δt 对照中，统计池化的 AUC 反而显著优于 Transformer 注意力（−1.98 与 −4.22，均经 Holm 校正显著），与 TwiBot-20 上的 +4.10 方向相反。最合理的解读是特征-任务适配：TwiBot-22 的微观分支接近随机水平（AUC 56～62），序列交互层的容量在弱信号下反而拟合噪声。这收窄而非推翻本文的主张——事件级注意力在 TwiBot-20 上的增益确凿且构成了完整模型 AUC 提升的来源，但它不是无条件成立的机制。

**未获得支持的是宏观快照演化。** 5.4 节的两项对照给出了一致的否定证据：加入宏观视图后 AUC 点估计下降（−0.17），而其内部的 8 快照 GRU 演化亦未优于直接取终态快照（ΔAUC = −0.10）；同时末快照变体本身相对基线有显著 AUC 增益（+0.38，$p_{\text{holm}}$ = 6.2×10⁻⁴）。**三者合起来指向一个明确的结论：宏观分支的有效成分是"第二条静态图通路"，而非"演化"。** 演化建模失效可能有三方面原因。（i）**创建时间作为演化锚点过于粗糙**：以 $\max(c_u,c_v) \le t_k$ 判定边存在是保守上界（3.3 节），它只能反映"账号何时**可能**建立连接"，而非连接实际建立的时刻，因而快照序列刻画的更接近**节点注册次序**而非真实的结构演化。（ii）**图过于稀疏**：TwiBot-20 的边集共 227,979 条而节点 229,580 个，平均度约为 1，逐快照掩码后早期快照极度稀疏，难以支撑稳定的结构表示。（iii）**GRU 末态被终态快照主导**：第 $K$ 个快照即完整图，单向 GRU 取末态时其信息自然占主导，演化轨迹的贡献被压缩。第一点是最根本的限制，也是单快照数据的固有代价——在边形成时间不可观测的前提下，"真实结构演化"这一建模目标本身就不可达，本文的负面结果与其说否定了动态图建模，不如说界定了它成立所必需的数据条件。

**未获得支持的还有跨视图注意力融合与 InfoNCE 对齐。** 二者的失效可用同一机制解释：当参与融合的视图判别力悬殊时（micro 与 global 相差 13 个百分点），**强制对齐或加权求和都会把强视图拉向弱视图**。支持该解释的最直接证据是 InfoNCE 的**剂量依赖性**——AUC 随 $\lambda$ 单调下降并在 $\lambda=1.0$ 处显著劣于基准，这正是"对齐强度越大、损害越大"的表现。该观察与近年多模态融合工作中"弱模态拖累"的现象一致，提示后续工作应转向保留各视图独立通路的融合方式（如拼接后由分类头自行选择，或按视图可信度做稀疏门控）。需要保留的是，本文并未直接测量融合后各视图的权重分布或表征相似度，上述机制目前仍是与数据一致的**假设**而非已验证的因果解释。

**一项贯穿全文的方法学观察。** 本文全部 56 项配对检验中，经全局 Holm 校正后仍显著的正向结论共 11 项，其中 10 项属于 AUC、仅 1 项属于 F1；而 5.2 节的验证集核验进一步显示，各变体的 F1 排名在验证集与测试集之间并不一致。这提示在 TwiBot-20 这一规模（测试集仅 1183 个样本）上，**基于固定阈值的 F1 不足以分辨 0.5 个百分点以内的差异**，相关文献中大量以 F1 小数点后一两位论优劣的比较可能并不稳健。本文建议此类工作一律同时报告 AUC、使用不少于 15 个种子并施加多重比较校正。

6 结论与局限性

本文针对主流社交机器人检测方法中"推文平均池化稀释异常证据"与"微观时序建模依赖高精度时间戳"两个共性问题，提出了 DTG-Bot 框架并在 TwiBot-20 上开展了包含 13 组变体、每组 15 个种子的系统实验。**本文认为，如实区分获得实证支持与未获得支持的部分，比宣称一个整体上更优的框架更有价值**，故将结论分述如下。

**获得支持的结论。**（1）**平均池化确实稀释了微观异常证据，事件级注意力是有效的补救。** 在仅微观分支的设置下，注意力池化相对统计池化取得 ΔAUC = +4.10、ΔF1 = +2.01（$p$ < 10⁻⁵）；在完整模型中，微观视图叠加到两种不同图骨干上均取得同向显著的 AUC 提升（+0.28 与 +0.20，$p_{\text{holm}}$ = 0.027 与 0.0031），证明该证据与图结构信息互补而非冗余。（2）**"发帖先后顺序携带判别信息"这一被广泛默认的前提，不成立——且该结论获得了外部数据集的独立复现。** 在 TwiBot-20 上，打乱事件次序后性能与原序在统计上不可区分（ΔF1 = −0.12，$p$ = 0.718；ΔAUC = −0.18，$p$ = 0.443），整体反序亦无影响；在列表已被实测保序（96.71% 相邻对）的 TwiBot-22 上，次序效应同样为零（ΔAUC = +0.01，$p$ = 0.972），即便加入真实时间通道后依然如此（ΔAUC = −0.71，$p$ = 0.185）。同时 TwiBot-20 原论文记载的 API 倒序抓取机制进一步排除了"数据集未保序"的替代解释。但边界必须精确：**无效的是离散的相对先后，而非时间信息本身**——在 TwiBot-22 上附加真实时间通道（$\Delta t$、昼夜相位、星期）后 AUC 显著提升最高 +3.86（$p$ < 10⁻¹⁵）。据此本文将微观分支定位为对**无序事件集合**的置换不变聚合，同时承认连续时间信息是尚未被当前架构利用的潜在增量来源。（3）**在完整框架层面，DTG-Bot 相对可信复现的 BotRGCN 基线取得了小幅但稳健的 AUC 提升**：默认配置 ΔAUC = +0.28（$p_{\text{holm}}$ = 0.0079），拼接融合下 ΔAUC = +0.49（$p_{\text{holm}}$ = 3.2×10⁻⁶）。需要强调该提升的量级是零点几个百分点，而非数个百分点；且**在 F1 上不存在稳定提升**——默认配置的 ΔF1 = +0.11 不显著，拼接融合虽在测试集上显著（+0.49）但未能在验证集上复现，故本文不主张 F1 增益。

**未获得支持的结论。**（4）**宏观快照演化分支未表现出价值。** 它既未优于仅用全局视图（ΔF1 = +0.15；ΔAUC = −0.17，均不显著），其内部的"8 快照 GRU 演化"也未优于直接取终态快照（ΔAUC = −0.10，$p$ = 0.271）；而终态快照本身却有显著增益（ΔAUC = +0.38 vs 基线）。**该分支的有效成分是第二条静态图通路，而非演化建模。**（5）**没有证据表明本文设计的跨视图注意力融合优于保留视图独立通路的简单方案**，点估计反而偏向后者（concat 与 gate 的 ΔF1 = +0.39 与 +0.35，$p_{\text{holm}}$ = 0.041），但该 F1 优势在验证集上未复现、在 AUC 上经校正后亦不显著，故本文仅作否定性表述而不断言拼接更优。（6）**跨视图 InfoNCE 对齐未带来增益**，且 AUC 随 $\lambda$ 单调下降，在 $\lambda=1.0$ 处显著劣于无对比损失的基准（ΔAUC = −0.32，$p_{\text{holm}}$ = 0.0052）；本文默认的 $\lambda=0.3$ 亦未优于 $\lambda=0$。（5）(6) 共同指向一个可推广的观察：**当参与融合的视图判别力悬殊时，强制对齐或加权求和都会损害强视图**——InfoNCE 的剂量依赖性负效应为此提供了最直接的证据，这对后续多视图机器人检测工作的架构选择具有直接的警示意义。

本文仍存在以下局限。**其一，时间信息的结论存在数据依赖，且注意力的有效性并非跨数据集稳定。** 离散次序的无效性已在两个数据集上独立复现，且 TwiBot-20 的 API 倒序抓取机制与同族数据集 96.71% 的实测保序率构成了完整证据链，该结论可以认为已闭环。但两点需要如实限定：（i）连续时间通道的增量（最高 ΔAUC = +3.86）是在 TwiBot-22 的**近随机微观单支**上观察到的（该分支 AUC 仅 56～62），该增益是否能在与图视图融合的完整模型中保留，尚需实验确认；（ii）事件级注意力的价值在 TwiBot-22 上未复现——统计池化的 AUC 反而显著优于 Transformer 注意力（−1.98 与 −4.22），说明注意力的增益依赖于事件特征的信噪比，而非普遍成立。**其二，宏观分支的失效原因未被完全隔离。** 5.5 节给出了三种可能解释，其中最根本的是以账号创建时间为锚点过于粗糙：$\max(c_u,c_v) \le t_k$ 只能反映"边何时可能建立"而非实际建立时刻，故快照序列刻画的更接近节点注册次序而非真实结构演化。如何在无合成数据的前提下获取真实的边形成时间，是该方向的关键前提。**其三，评估指标与统计功效的限制。** 训练过程仅记录了验证集 F1 而未记录验证集 AUC，致使本文最主要的 AUC 结论未能在验证集上做同等核验；同时 TwiBot-20 测试集仅 1183 个样本，即便使用 15 个种子，F1 上 0.5 个百分点以内的差异仍不足以稳定分辨。**其四，主实验尚未覆盖 TwiBot-22 与更广的基线集合。** 本文目前仅完成了对 BotRGCN 的可信复现与对比，RGT、BotMoE、BotDGT 等方法尚未在统一协议下复现；按本文自设准则，未复现到官方水平的基线不参与对比，故相应结论有待补充。**其五，当前微观分支在零推文账号上退化为常量向量**，对该类样本的判别完全依赖图视图，其与邻居信息的交互方式值得进一步研究。 **(****参考文献)**
